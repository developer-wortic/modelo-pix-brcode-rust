# Segurança

Se você achar uma falha de segurança, não abra issue pública. Relate em privado pelo [aviso de segurança do GitHub](https://github.com/developer-wortic/modelo-pix-brcode-rust/security/advisories/new).

Inclua o que você encontrou, como reproduzir e o impacto que você vê.

Não envie chave Pix real, senha, CPF ou outro dado pessoal no relato. Use dados de exemplo.

Só a versão mais recente da branch principal recebe correção. Vamos responder pelo mesmo canal.
